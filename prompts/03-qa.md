# Prompt --- QA / Red team funcional

Com base no ROADMAP e no diff atual, crie e execute uma matriz de
testes.

Cubra happy path, entradas inválidas, limites, concorrência, reinício,
falhas de rede simuladas, autorização cross-tenant, timezone, duplicação
e retries.

Não altere produção para fazer o teste passar. Para cada falha entregue:
pré-condição, passos, esperado, observado, severidade, evidência e teste
automatizado recomendado.

Finalize com GO/NO-GO para a fase seguinte.
